# GuitarTocar VST Plugin

**GuitarTocar** — это аудио-плагин в формате VST3 для электрогитары, разработанный на C++ с использованием фреймворка JUCE. Плагин предназначен для обработки звука и добавления эффектов (усиление, эквалайзер, реверберация) в реальном времени.

##  Основные возможности (Features)
*   **Gain** — регулировка входного усиления с мягким клиппингом (имитация лампового перегруза).
*   **3-полосный эквалайзер** (Bass, Middle, Treble).
*   **Presence** — регулировка высоких частот для добавления "воздуха" и четкости.
*   **Master** — общая громкость плагина.
*   **Reverb / Volume** — управление пространственными эффектами и выходной громкостью.
*   Поддержка автоматизации параметров в DAW (Reaper, FL Studio, Ableton и др.).
*   Интерактивный GUI с фоновым изображением и всплывающими ручками.

##  Требования для сборки (Prerequisites)
Для сборки проекта вам понадобятся:
*   **JUCE Framework** (версия 7 или выше) — [скачать здесь](https://juce.com/).
*   **Projucer** (входит в состав JUCE).
*   **Visual Studio 2022** (с установленной рабочей нагрузкой "Разработка классических приложений на C++").
*   **Windows 10/11** (текущая сборка настроена под Windows, но JUCE позволяет собрать под macOS).
